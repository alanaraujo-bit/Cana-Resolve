# Identidade visual — Canaã Resolve

Este diretório reúne os arquivos de marca e comunicação do projeto.

## Avatar para redes sociais

- `social-avatar-2026-08.png`: imagem de perfil quadrada, preparada para o grupo do WhatsApp e para o Instagram. O desenho mantém área segura para o recorte circular e não usa texto, preservando a leitura em tamanhos pequenos.

### Uso recomendado

Envie o arquivo original diretamente como foto de perfil. WhatsApp e Instagram farão a adaptação automática; evite capturas de tela ou reexportações com compressão.

### Elementos da direção visual

- Verde profundo: base de confiança e proximidade.
- Curvas de nível: referência discreta à topografia de Canaã dos Carajás.
- Pino e confirmação: conexão local com resolução prática.
- Terracota: calor humano e ponto de destaque.
